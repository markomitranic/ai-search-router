# Extension Icons

This directory should contain the extension icons in the following sizes:

- `icon-16.png` - 16x16 pixels (browser toolbar)
- `icon-48.png` - 48x48 pixels (extension management page)
- `icon-128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create icons using any design tool. The icon should:

- Be visually recognizable at small sizes
- Represent the concept of "routing" or "AI search"
- Use colors that work well with both light and dark themes

## Placeholder

For development, you can create simple placeholder images or use the emoji "🔀" as the visual representation.

## Tools

- [Figma](https://www.figma.com) - Free design tool
- [GIMP](https://www.gimp.org) - Free image editor
- Online favicon generators - Can create multiple sizes at once
