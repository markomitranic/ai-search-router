📋 Setup Guide

Set this extension as your default search provider for instant routing

1
Copy the search URL
chrome-extension://loading.../search.html?q=%s
2
Open Chrome search settings

Go to chrome://settings/searchEngines or click the button below

3
Add a new search engine

Click "Add" next to "Site search", then fill in:

  • Name: AI Search Router
  • Shortcut: @ai (or any keyword you prefer)
  • URL: Paste the URL from step 1
4
Set as default (optional)

Click the three dots next to your new search engine and select "Make default" for all searches to be routed automatically.
